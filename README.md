# add-reviewers

CLI that automatically adds pull request reviewers based on past approvals.

## Install Dependencies

```bash
pip install .[dependencies]
```

## Usage

```bash
add-reviewers --help
```

## Development

This project uses [Hatch](https://hatch.pypa.io/) as the build backend.

### Install in development mode

```bash
pip install -e .
```

### Run the CLI

```bash
add-reviewers hello
```
